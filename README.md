A modern, high-performance personal developer portfolio for **Inhamul Hasan**, built with **React 18**, **Vite**, and **Tailwind CSS**. Designed with an editorial, magazine-inspired aesthetic featuring a signature golden-orange sun backdrop, hand-drawn annotations, dark ribbon skill showcase, and direct contact integration.

---

## 🌟 Key Highlights & Features

- **🎨 Editorial Hero Design**: Warm `#FF6A00` sun backdrop with concentric geometry, authentic circular avatar frame, hand-drawn doodle accents, and interactive credibility badges.
- **⚡ Core Projects Showcase**:
  - **Malware Detection System**: AI-powered malware detection engine using Python, Scikit-learn, and Pandas to analyze system-call patterns with >90% detection accuracy.
  - **RESTful Task Management API**: Production-ready Flask REST API with JWT authentication, relational MySQL persistence, and Swagger/OpenAPI documentation.
  - **Full-Stack E-Commerce Platform**: Decoupled React & Node/Express storefront with Stripe checkout, product management, and MongoDB database.
  - **Real-Time AI Chat Application**: Contextual conversational chat using OpenAI API and bidirectional Socket.io streaming.
  - **Collaborative Task Management**: Modern Next.js application with Prisma ORM, PostgreSQL database, and Kanban sprint boards.
  - **3D Developer Portfolio**: Modern interactive portfolio built with Three.js canvas, Framer Motion, and Tailwind CSS.
- **📬 Functional Contact System**: Real-time form submissions powered by FormSubmit with instant delivery to `inhamul07@gmail.com` and one-click email client fallback.
- **📱 Fully Responsive**: Tested across desktop (1920px, 1440px), tablet (1024px, 768px), and mobile viewports (430px, 390px, 360px).
- **✨ Micro-Interactions**: Confetti celebration triggers, glassmorphic floating pills, and smooth section navigation.

## 💻 Local Development Setup

### Prerequisites
- Node.js >= 18.0.0
- npm >= 9.0.0

### Installation

```bash
# 1. Navigate into project directory
cd portfolio-main

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Visit `http://localhost:5173` to explore the portfolio locally.

### Production Build

```bash
# Generate optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
